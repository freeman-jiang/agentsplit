# Security

## Report a vulnerability

Do not report a vulnerability in a public issue, pull request or discussion.

1. Open the **Security** tab of this repository on GitHub.
2. Select **Report a vulnerability**.
3. Give the commit that you tested, the steps that show the problem, and its effect.

GitHub keeps the report private between you and the maintainer.

## Test safely

Test against your own local copy of AgentSplit ([README.md](README.md), "Develop"), with synthetic data. Never test against an instance that holds the data of other people, and never read, change or delete data that is not yours.

## Spliit

AgentSplit is a fork of [Spliit](https://github.com/spliit-app/spliit). If the vulnerability is also in Spliit, report it to Spliit too.
